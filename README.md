# Лабикс 2.0 — интерактивная библиотека знаний

Готовый статический сайт для GitHub Pages: HTML + CSS + JavaScript, без сборщика, npm и серверной части.

## Что внутри

- `index.html` — главная страница с каталогом 15 материалов.
- `assets/styles.css` — единая светло-бежевая тема, адаптивность.
- `assets/catalog.js` — каталог материалов. **Все новые уроки добавляются здесь**, по образцу уже существующих элементов.
- `assets/app.js` — поиск, фильтры, избранное (`localStorage`), сортировка.
- `lessons/addition.html` — собственный интерактивный урок математики.
- `assets/addition.js` — логика урока (яблоки, числовая прямая, 10 задач).
- `assets/favicon.svg` — значок сайта.
- `.nojekyll` — GitHub Pages не запускает Jekyll.

## Публикация на GitHub Pages

1. Распакуйте ZIP.
2. Создайте **новый** репозиторий или сохраните резервную копию существующего, прежде чем заменять в нём файлы.
3. Загрузите **содержимое** папки `labix-2.0` в корень репозитория (не вкладывайте папку целиком).
4. GitHub → репозиторий → **Settings → Pages → Build and deployment → Deploy from a branch**; выберите `main`, папку `/(root)` и сохраните.
5. После публикации откройте адрес, который сообщит GitHub Pages. Для пользовательского репозитория типичный адрес — `https://имя.github.io/репозиторий/`.
6. Для собственного домена позже укажите его в **Settings → Pages → Custom domain**, затем настройте DNS у регистратора и включите HTTPS. Сам домен ещё не куплен.

**Важно:** это обновлённая отдельная сборка на основе имеющегося каталога «Атлас идей». Она не заменяет действующий сайт автоматически и не меняет исходные проекты.

## Как добавлять новые уроки

Откройте `assets/catalog.js`, добавьте объект в массив `LABIX_LESSONS` (с уникальным `id`). Внешние `https`-ссылки откроются в новой вкладке; локальные ссылки пишите в формате `./lessons/имя.html`.

Доступные категории: `math`, `electricity`, `mechanics`, `engineering`, `coding`, `space`. Цвета карточек: `pink`, `gold`, `mint`, `lavender`, `blue`. Счётчики категорий пересчитываются автоматически.

## Перед коммерческим запуском

- Проверить доступность всех внешних уроков после размещения (в среде создания не удалось проверить ответы внешних серверов).
- Добавить `sitemap.xml`, канонические URL и Open Graph для **реального зарегистрированного** домена.
- Подготовить необходимые сведения о владельце, правила, политику обработки данных и уведомления в соответствии с фактически подключаемыми сервисами.
- Проверить условия GitHub Pages для выбранной модели монетизации и при необходимости перенести хостинг без смены домена.
- При подключении рекламы и аналитики учитывать детскую аудиторию.

Избранное и лучший результат теста хранятся **только на устройстве пользователя** через `localStorage`. Серверной базы данных, трекеров и встроенной рекламы пока нет. CSS использует системные шрифты и не требует подключения Google Fonts.

## Быстрый тест локально

Откройте `index.html` в браузере. Для тестирования через HTTP можно выполнить `python3 -m http.server 8000` в папке проекта и перейти на `http://localhost:8000/`.
